# Snake Game

A classic Snake Game developed using Core Java and Java Swing. The player controls a snake that moves around the screen, eats food (apples), and grows longer. The game ends when the snake collides with itself or the screen boundaries.

## Features

- Interactive GUI using Java Swing
- Real-time snake movement using keyboard controls
- Random food generation
- Score tracking system
- Collision detection
- Game Over screen
- Smooth gameplay with timer-based updates

## Technologies Used

- Core Java
- Java Swing
- AWT Event Handling
- OOP Concepts
- Arrays
- Random Class
- Timer

## Controls

| Key | Action |
|------|---------|
| ↑ | Move Up |
| ↓ | Move Down |
| ← | Move Left |
| → | Move Right |

## How to Run

1. Open the project in Eclipse or any Java IDE.
2. Compile and run `SnakeGame.java`.
3. Use the arrow keys to control the snake.
4. Eat apples to increase your score.
5. Avoid hitting the walls or the snake's own body.

## Game Rules

- Each apple eaten increases the snake length.
- Score increases by 1 for every apple eaten.
- The game ends if:
  - The snake hits the wall.
  - The snake collides with its own body.
